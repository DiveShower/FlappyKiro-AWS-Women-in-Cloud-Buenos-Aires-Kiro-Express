ENG: Project created as a result of the AWS Women in Cloud Buenos Aires Kiro Express event. It is a Flappy Bird remake featuring our friendly pal Kiro as the main character.

I combined my gamer, designer, and developer sides to build a project using the Spec-Driven Development framework—an agentic development approach demonstrated at the event. Using well-structured prompts, I integrated Clean Architecture into the corresponding markdown file (design.md), fully leveraging KiroIDE's capabilities.

The game is playable at the following link:
https://flappy-kiro-aws-women-in-cloud-buen.vercel.app
